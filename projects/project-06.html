Paint Program

ART 101 · p5.js interactive program

Play the paint program

The idea

A paint program I built in p5.js with three custom brushes (a star stamp, a fairy light spray, and a zigzag line) and an eraser. Press 1, 2, or 3 to pick a brush, 4 for the eraser, then click and drag. Press X to clear the canvas.

Process

Each brush is its own function that takes values like size and spread, so I can reuse it and change how it looks without rewriting it. A switch statement picks whichever brush is selected. Here is the star brush:

function htStarStamp(cx, cy, points, size) {
  push();
  translate(cx, cy);
  noStroke();
  fill(255, 200, 0, 200);

  let innerSize = size * 0.5;

  // goes around the circle and swaps between the big and small radius to get the points
  beginShape();
  for (let i = 0; i < points * 2; i++) {
    let angle = map(i, 0, points * 2, 0, TWO_PI);
    let r = (i % 2 === 0) ? size : innerSize;
    vertex(cos(angle) * r, sin(angle) * r);
  }
  endShape(CLOSE);
  pop();
}

What I learned

I learned how functions and switch statements can make an interactive program easier to organize and reuse. Next time, I would add more controls for changing brush colors and sizes while the program is running.
