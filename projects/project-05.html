Creative Coding: Robot

Art 75 · p5.js animation

Open the sketch in p5.js

The idea

This project is taking more advanced steps in p5.js and coding a robot in your own design. Another addition is to create a small animation.

Process

I built the robot using basic shapes such as ellipses and a triangle for the body. I used different colors to create the robot’s head, face, eyes, and body, then added animation by using an angle variable to make part of the robot move. One problem I solved was keeping the robot’s shapes aligned while adding the movement, so the animation would not make the character look disconnected.

What I learned

I learned how simple shapes can be combined to create a more detailed character and how variables can be used to add motion. Next time, I would make the animation more complex and add more movement to the robot’s body or facial features.
