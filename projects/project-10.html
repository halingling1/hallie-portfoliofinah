The idea

This project was about learning the first few steps of CodePen: headers, paragraphs, and adding images. I made a self-introduction out of this assignment.

Process

I built a simple self-introduction page using HTML headings, paragraphs, decorative text, and an image. I organized the information into separate sections so I could introduce where I am from, what I study, and some of my interests. Through this process, I learned how HTML elements create the basic structure of a webpage and how images can be added to make the page more personal.

What I learned

I learned how headings, paragraphs, and images work together to create a basic webpage. Next time, I would spend more time styling the page and organizing the information so it feels more visually developed.
